## ทำอะไร
- `baselines/plot_p32.py` ทำทุกกราฟใน `docs/reports/2026-11-19-paper32-figure-plan.md` (Exp 1–5 + ที่ตกลงเพิ่ม) เป็น line chart,
  ไม่มี title, png + pdf, หนึ่งไฟล์ต่อหนึ่งตัววัด (B5 เลือกและรวมใน LaTeX ได้) + `figure_points.csv` (ทุกตัวเลขที่ plot) +
  `README.md` (ทุกกราฟ, ข้อมูลที่ใช้, หมายเหตุความยุติธรรม)
- ค่า = mean ของ 10 run หลัง warm-up 3 (#46), จุดละ = mean ของ query / keyword / domain ที่ x นั้น; ไม่มี error bar
- 3 ตัววัดของทุก query experiment: server search อย่างเดียว (AMTP `server_search_pf`, Chen `server_total`, SE-COLLAB / Du
  `search_no_fetch`), DU verify (`verify_total`), end-to-end; SE-COLLAB ใช้ `proof_mode=paths`; 1 KB = 1000 B (`plot_results.KB`)
- Boolean multi domain, multi-domain verify, xdomains, Exp 5: AMTP vs SE-COLLAB เท่านั้น (เจ้าของงาน); Exp 5 `--with-du` เพิ่มจุด Du
  ที่ n_c = 4–32 (แบบ B; ค่าเริ่มต้นแบบ A)
- gas: `e5_sepolia_gas` (Sepolia) สำหรับ paper; `e5_root_gas_localevm` มีป้ายห้ามใช้ (ตาราง gas ของ py-evm ≠ Ethereum: 64.1k vs 86.7k
  ที่ D = 1 ธุรกรรมเดียวกัน)
- ชื่อไฟล์: `e1_single_{kq,n}_<m>`, `e1_multi_<shape>_<m>`, `e1_domains_<m>`, `e2_layout_<layout>_<m>`, `e2_layouts_<m>`,
  `e2_single_verify_<m>`, `e2_tamper_<kind>_{detection,verify}`, `e2_multi_verify_<m>`, `e3_{b,n}_{update,per_request,throughput,
  breakdown_insert,breakdown_delete}`, `e4_{update_insert,update_delete,restructure,splits_merges,max_partition,query_server,
  query_verify,proof_kb,batches_skew0.95}`, `e5_query_<m>`, `e5_{isolation_update,isolation_protocol,root_anchor_ms}`,
  `e5_sepolia_{gas,time}` (m = search, query_gen, server, proof, verify, e2e, proof_kb)

## ทดสอบ
รันกับข้อมูล smoke (Mac) + ผลจริงที่มีแล้ว (ex3 w10, ex4 บางส่วน, ex5 รอบแรก): 61 + 12 กราฟ ไม่มี error; ดูภาพแล้ว (เส้นทับกันที่ 0 / 100 %
