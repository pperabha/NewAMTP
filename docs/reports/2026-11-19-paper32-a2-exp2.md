# A2: Exp. 2 ของ (32) (Selective Proof and Verification: clustered vs dispersed)

วันที่ 19 พ.ย. 2026 · คน A · branch `feat/paper32-a2-exp2` (แตกจาก `feat/paper32-experiments` 8cd9fc7)

## (32) บอกว่าอะไร
"The total database size is fixed at N […] pQ, rQ, and sQ are varied through queries with different selectivities and
posting distributions. Both clustered queries, whose matches are concentrated in a small number of partitions, and
dispersed queries, whose matches span many partitions, are considered. We measure proof-generation latency, DU
verification latency, and proof size." (N = 100k ตามที่ตกลง 18 พ.ย. แทน 10^6)

## ทำอะไร
- `baselines/results/exp2_layouts.json` สร้างใหม่บน dataset-v4 ที่ N = 100,000 (ไฟล์เดิมเป็น v3 / 200k):
  `cd amtp_code && python -m bench.experiments exp2-layouts --n 100000` ด้วย config ของ paper (32) (`scripts/paper32_env.sh`)
  - domain D1–D4 คนละ 25,000 ไฟล์ รวมเป็น AMTP domain เดียว (แบบเดียวกับ Exp 3 `update`), θ 64/16, placement fill
  - AMTP วางไฟล์ได้ 2,240 partitions (ใหญ่สุด 63)
  - marker keyword ที่มีผลพอดี rQ ∈ {10, 100, 1000, 5000} ไฟล์ ใน 3 แบบ:
    `clustered` (rQ ไฟล์ติดกันเริ่มที่ N/3 → อยู่ใน partition น้อย), `dispersed` (ทุก N/rQ ไฟล์ → กระจาย),
    `partition_spread` (ไฟล์ละ partition วนรอบ = กรณีแย่สุดของ AMTP)
  - ทุก scheme อ่านไฟล์นี้ไฟล์เดียว → ไฟล์ชุดเดียวกัน keyword เดียวกัน
- `scripts/aws_run_all.sh`: step ใหม่ `exp2` (AMTP ผ่าน `$AMTP_MOD` = `bench_split.run` จึงได้ `server_search_pf` ด้วย,
  Chen `--scope full --edb memory`, Du, SE-COLLAB `--proof-mode paths`; SE-COLLAB suite นี้วัดทั้ง paths และ multiproof)
  และใส่ใน default steps หลัง `xdomains`
- `scripts/smoke_all.sh`: หมายเหตุว่า exp2 ย่อขนาดไม่ได้ (N มาจากไฟล์ layout)

## วัดอะไร (คอลัมน์)
- proof generation: AMTP `server_proof_ms`, SE-COLLAB `proof_gen_ms` (Chen / Du ไม่มีขั้นสร้าง proof แยก)
- DU verification: `verify_total_ms` ทุก scheme · proof size: `proof_bytes` ทุก scheme · AMTP มี `sQ` (partition ที่ครอบ)
- ค่า = mean ของ 10 run หลัง warm-up 3 (#46)

## ทดสอบ
- smoke `bash scripts/smoke_all.sh exp2` บน Mac (REPS 1, ของจริงทั้งหมด: BSW07, ABS MPR SS512, chain-local) ผ่านทั้ง 4 scheme ที่ N = 100k:
  AMTP 581 s, Chen 157 s, Du 101 s, SE-COLLAB 16 s, ไม่มี FAIL; ทุก query ได้ผลพอดี rQ
- ตัวอย่าง AMTP (smoke 1 run, Mac) ที่ rQ = 1,000: clustered sQ 39, proof 55 KB, สร้าง proof 0.59 ms, verify 11.6 ms; dispersed sQ 880,
  proof 320 KB, 5.2 ms, 23.3 ms → AMTP ทำงานตามจำนวน partition ที่ครอบ (สิ่งที่ (32) Exp 2 ต้องการแสดง)
- pytest ไม่เปลี่ยน (ไม่แก้โค้ด Python)
